# История тренировок

Реализовано локально 29 октября 2026. Публикация и проверка на реальном iPhone не выполнены.

## Сценарий

«Начать тренировку» создаёт одну активную сессию выбранного дня. Название дня, названия, группы и заметки упражнений копируются в сессию; подходы получают плановые повторения и вес, но остаются невыполненными. Старые галочки программы не превращаются в исторические результаты.

В сессии можно изменить повторения и вес каждого подхода, отметить выполнение, добавить подход или убрать последний. Для удаления выполненного подхода требуется подтверждение. «Сохранить прогресс» сохраняет все поля на сервере. Незаписанные поля защищены предупреждением при переходах по ссылкам приложения и закрытии страницы; это не офлайн-очередь. После сохранения тренировку можно продолжить в другом браузере. Конфликт версии отклоняет запись и загружает актуальное серверное состояние.

«Завершить тренировку» сохраняет фактические результаты в историю. Если остались неотмеченные подходы, показывается подтверждение; такие подходы не считаются выполненными. История доступна через `/gym/#history`, дополнительная настройка Nginx не нужна. Завершённые сессии доступны для просмотра; изменения программы и удаление упражнений не меняют их. Предыдущий результат ищется среди завершённых сессий по стабильному ID упражнения и показывает только выполненные подходы.

Отмена активной сессии требует подтверждения и не удаляет программу или прошлые тренировки. Общий сброс тренировок удаляет и программу, и историю; текст подтверждения это явно указывает.

Интерфейс программы обновлён 29 октября: новый день получает автоматическое название `День N`, а пользователь выбирает только привязку к неделе и группы мышц. Удаление дня доступно рядом с его настройкой. При добавлении упражнения сначала предлагается каталог, затем ручная форма; переход с экрана тренировки больше не открывает форму и клавиатуру автоматически. Действия переноса старых локальных записей и скачивания локальной копии находятся в общих настройках тренировок. Иконки групп мышц — единый набор SVG. Отступы карточек истории нормализованы между четырьмя темами.

## Хранение и совместимость

Необязательное поле `sessions` в состоянии `gym` использует существующие версии, защиту повторных операций и `/api/gym`.

- Сессия: `id`, `dayId`, `name`, `date`, `timezone`, `startedAt`, `finishedAt`, `exercises`.
- Снимок упражнения: `id`, `name`, `group`, `note`, `sets`.
- Подход: `reps`, `weight` (число либо пустая строка), `done`.
- Не более 1000 сессий, одна незавершённая, до 500 упражнений и 50 подходов каждого упражнения; общий лимит API остаётся 10 MB. Автоматического удаления истории нет.
- Дата фиксируется в часовом поясе устройства при старте и не меняется при поездке. Начало/завершение имеют UTC-смещение. Сервер проверяет дату, порядок времён и числовые диапазоны.
- Завершённый снимок нельзя переписать обычным сохранением. Прежний клиент без `sessions` сохраняет существующие сессии при записи программы. Явный полный сброс использует `command: "reset"`.
- Экспорт schema 2 включает сессии и показывает их число при предпросмотре. Восстановление старой копии без `sessions` возвращает пустую историю: это восстановление состояния копии, а не слияние.

## Таймер

Кнопки отдыха: 60, 90 и 120 секунд, сброс. Конец интервала хранится в `sessionStorage` текущей вкладки с ID сессии; отображение рассчитывается от абсолютного времени и восстанавливается после перезагрузки. Таймер не синхронизируется между устройствами, не отправляет push и не гарантирует сигнал при заблокированном экране.

## Проверки и публикация

```text
python -m unittest discover -s backend -p "test_*.py"
python preview-local.py --port 4190
python test-gym-history.py
```

Браузерный тест использует настоящий локальный API и временную базу просмотра. Проверяет снимки, подходы, отмену, второе устройство, конфликт, удаление программы, предыдущий результат, таймер, экспорт, четыре темы на 320/390 px с увеличенным текстом. Реальные push не отправляются.

Публиковать согласованно: `backend/wellness.py`, `backend/data_portability.py`, `gym-prototype/dist/{index.html,app.js,history.js,history.css}`, `dist/hub/chrome.js`. Если публикуется весь текущий набор правок чата, включить также обновлённые `gym-prototype/dist/catalog.js` и `dist/food/planner.js`. Соблюдать общую процедуру сравнения с сервером, резервных копий и рестарта API. Исторические частичные release-скрипты сами по себе этот набор не устанавливают.
