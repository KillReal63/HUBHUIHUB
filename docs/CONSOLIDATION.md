## Дальнейшая работа

Одна задача — отдельная ветка в HUBHUIHUB, проверка, коммит и публикация конкретной версии. Не публиковать старые архивные версии отдельных приложений поверх общего backend или Nginx. Скрипты publish-hub.sh и publish-tasks.sh обновляют только перечисленные в них компоненты; они не являются полным установщиком всего проекта. Пути размещения и существующие команды описаны в корневом README.

База, личные записи, сессии, push-подписки, SSH-ключи и сертификаты не входят в Git. Истории Git сохранены; GitHub issues, настройки репозиториев и прочие данные вне Git в эту консолидацию не входят.
