# TABLETOCKA

Дизайн мобильного приложения для личного учёта приёма лекарств и добавок. Основной сценарий — Safari на iPhone.

Сейчас в репозитории лежат интерактивные дизайн-макеты. Код существующего приложения будет добавлен отдельно; настоящие уведомления в нём уже настроены.

## Посмотреть дизайн

Скачайте или клонируйте репозиторий и откройте HTML-файл в браузере:

- **[Фокус: пять стилей](design/focus.html)** — выбранная композиция. Слива, Рассвет, Прилив, Уголь и Стекло. Панель сверху переключает оформление.
- **[Первоначальные направления](design/directions.html)** — Ясно, Ритуал, Кассета и Фокус, сохранены для сравнения.

Установка зависимостей и сборка не нужны. Для загрузки шрифтов и ресурсов просмотрщика нужен интернет. Ссылки на HTML внутри GitHub открывают исходный код, а не работающий макет. GitHub Pages не настроен.

В макетах можно отметить приём, отменить отметку, отложить напоминание, посмотреть препарат и историю. Это демонстрационные взаимодействия: они не отправляют уведомления и не меняют реальные данные. Выбор стиля и отметки могут сохраняться локально в браузере.

## Что выбрано

Композиция **«Фокус»**: ближайшее время → препарат → количество и условие приёма → главное действие → следующий приём → нижняя навигация.

Пользователю нравятся все пять стилей. Финальная тема пока не выбрана; «Стекло» — последний добавленный эксперимент с полупрозрачными элементами и плавающей нижней панелью. Это веб-интерпретация Liquid Glass, а не нативный материал iOS.

## Файлы

```text
design/
  focus.html               Самостоятельная страница с пятью стилями
  directions.html          Самостоятельная страница с четырьмя композициями
  sources/
    focus.html             Исходный HTML-фрагмент пяти стилей
    directions.html        Исходный HTML-фрагмент первых направлений
  HANDOFF.md               Решения и ориентиры для переноса
PRODUCT.md                 Контекст продукта
```

`sources` — редактируемые фрагменты с CSS и демонстрационной логикой. Самостоятельные страницы экспортированы из них с оболочкой просмотра. При изменении фрагмента самостоятельную страницу нужно обновлять отдельно. Для интеграции берите структуру и стили из фрагментов, не переносите оболочку просмотрщика в приложение.

## Продолжить на другой машине

```sh
git clone https://github.com/KillReal63/TABLETOCKA.git
cd TABLETOCKA
```

Добавьте существующее приложение с сохранением папки `design/`, прочитайте [заметки по переносу](design/HANDOFF.md) и подключите дизайн к его данным и готовой системе уведомлений. В этом репозитории не навязывается новый стек приложения.
