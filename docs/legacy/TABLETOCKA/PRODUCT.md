# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

The existing application is on another computer. This task creates an isolated interactive design mockup in the conversation, not a new application or framework scaffold.

## Users

The owner tracks a few personal medications and supplements.

## Product Purpose

Make the next scheduled intake clear and show which intakes have already been recorded.

## Operating Context

Mobile Safari is the primary design target. Existing web notifications are already configured; their implementation is outside this design task.

## Capabilities and Constraints

The user chose the Focus composition from four initial directions. Five Focus styles are available: Plum, Dawn, Tide, Coal, Glass. All five are liked; no final palette has been selected. Compare them through an absolutely positioned switching panel. All interactions are mockup-only. Existing application code is unavailable and must not be replaced by a new site.

## Brand Commitments

The existing design is minimal and the user allows creative freedom. Russian interface copy. No confirmed product name or brand assets.

## Evidence on Hand

User brief and official Apple Health, Medisafe and MyTherapy product descriptions reviewed on 2026-09-17. No screenshots or actual medication data were supplied.

## Product Principles

- Prioritize the next intake and clear recorded states.
- Keep interaction feasible with one hand.
- Compare composition as well as color.
- Use illustrative medication data only; no treatment recommendations.
