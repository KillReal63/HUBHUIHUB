# Ритм — трекер тренировок

Сайт: https://144.31.166.231/gym/

Две страницы: тренировка (/gym) и редактор программы (/gym/program). Дни недели, группы мышц, упражнения, подходы, повторения, вес, заметки, изменение порядка и отметки выполненного. Четыре оформления.

## Локальный запуск

Node.js, без установки зависимостей: `node server.cjs`.
Открыть http://127.0.0.1:4182/gym.

## Данные

Программа и отметки хранятся только в localStorage браузера, отдельно для каждого адреса и устройства. Серверной синхронизации и аккаунтов нет. Начальная программа — редактируемый пример. Личные записи не входят в репозиторий.

## Публикация

Статические файлы из dist размещены в /var/www/gym. Nginx использует deploy/nginx-gym.conf внутри существующего HTTPS server-блока. Локальный Node-сервер на VPS не нужен.

Проверка: `node --check dist/app.js` и `node --check dist/themes.js`.
