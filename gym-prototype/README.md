# Ритм — трекер тренировок

Сайт: https://144.31.166.231/gym/

Три страницы: тренировка (/gym), редактор программы (/gym/program) и каталог упражнений (/gym/catalog). Дни недели, группы мышц, упражнения, подходы, повторения, вес, заметки, изменение порядка и отметки выполненного. Четыре оформления.

## Локальный запуск

Node.js, без установки зависимостей: `node server.cjs`.
Открыть http://127.0.0.1:4182/gym.

## Данные

Программа и отметки хранятся только в localStorage браузера, отдельно для каждого адреса и устройства. Серверной синхронизации и аккаунтов нет. Начальная программа — редактируемый пример. Личные записи не входят в репозиторий.

## Публикация

Статические файлы из dist размещены в /var/www/gym. Nginx использует deploy/nginx-gym.conf внутри существующего HTTPS server-блока. Локальный Node-сервер на VPS не нужен.

Проверка: `node --check dist/app.js` и `node --check dist/themes.js`.

## Общий вход

С 30 сентября 2026 вход находится в хабе https://144.31.166.231/ . В production Nginx проверяет общую сессию через `/api/auth-check`. Полная конфигурация — `../deploy/nginx-https.conf`; отдельный фрагмент не добавлять поверх неё. Локальный статический сервер предназначен для предпросмотра и не проверяет авторизацию. Авторизация не переносит localStorage на сервер.
